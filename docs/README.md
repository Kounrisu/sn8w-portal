# docs/

Public documentation for this repo — committed to GitHub. `docs_sensitive/`
at the project root holds anything that shouldn't go there: actual
secrets/personal material (CVs, cover letters, application-specific
material, local infra notes), but also mood boards, design references, or
other heavy/draft assets not worth bloating the repo's history with.

> **`docs_sensitive/` exists locally on this machine but is not in this
> repo** (it's gitignored — see `.gitignore`). If you're reading this on a
> different machine or a fresh clone, that folder won't be here; check the
> other machine (Lenovo / MacBook) or wherever you keep it before assuming
> the content is gone.

## screenshots/

Source screenshots of this app and other showcased projects, used as the
vignette images on the sn8w Portal homepage. Keep one clearly-named image
per project here (e.g. `lotokarma-home.png`) and upload it through the
portal's own admin when the project card needs updating — this folder is
the versioned source copy, not a live pipeline into the site.
